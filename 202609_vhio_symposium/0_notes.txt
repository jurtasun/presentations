Modification calls (m6A, m5C, etc.) live in the MM / ML BAM tags that Dorado writes during basecalling
Mod Matrix (MM) site
Mod likelihood (ML) likelihood


pod5 (raw signal)
   │
   ▼
dorado basecaller  ← modifications are called HERE, at basecalling, from raw signal
   (base model + m6A_DRACH@v1 + m5C_2OmeC@v1)
   │
   │  every read gets: sequence + per-base quality + MM/ML tags
   │  (MM/ML = the modification calls: which positions, which mod, what probability)
   │
   ▼
unaligned BAM (uBAM)  — MM/ML tags already baked in, alignment-independent
   │
   ▼
minimap2  (or dorado aligner, which wraps minimap2)  ← MUST use -y flag
   │
   ▼
aligned BAM  — MM/ML tags carried through, now positioned against GRCm39

```
BAM=bam_pass/<some_file>.bam   # or your test_modcalls.bam from the SUP+modbase quick check

# 1) does the header show which basecalling/modbase models were used
samtools view -H "${BAM}" | grep -i 'PG\|basecall\|modbase\|DS:'

# 2) look at tags on a single read to see if MM/ML are present at all
samtools view "${BAM}" | head -1 | tr '\t' '\n' | grep -E 'MM:|ML:'

# 3) count how many reads actually carry modification tags (vs total reads)
echo "reads with MM tag: $(samtools view "${BAM}" | grep -c 'MM:Z:')"
echo "total reads:        $(samtools view -c "${BAM}")"

# 4) proper summary if modkit is available (env: ont_modqc)
modkit summary "${BAM}"
```
